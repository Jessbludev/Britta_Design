# IconForge Theme System

Incluye **15 familias × 5 variantes = 75 packs**. Cada pack define colores y estilos tipados para fondo, superficies, TopBar, BottomBar, NavBar, tabs, FAB, botones, iconos, estados de foco, cristal y glow.

Las variantes son `dark`, `light`, `crystal-glass`, `aqua-ocean` y `neon`. Usa `theme-packs.json` en tooling, `iconforge-themes.css` en web y `IconForgeThemes.kt` como catálogo tipado para Android/Compose.
