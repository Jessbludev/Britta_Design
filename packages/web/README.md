# @jessbludev/britta-design-web

Paquete Web portable de Britta Design. Incluye catálogo de iconos SVG, 75 temas JSON, CSS de tokens, fuente IconForge WOFF2 y estilos de integración.

```bash
npm config set @jessbludev:registry https://npm.pkg.github.com
npm install @jessbludev/britta-design-web
```

```js
import { iconCatalogUrl, themeCatalogUrl, iconFontCssUrl } from "@jessbludev/britta-design-web";
```

El paquete no registra telemetría, no hace llamadas de red y no emite logs.
